# 역사네컷 · 나주역 1929 (v2.0)

학생독립운동기념일(학생의 날) 행사용 네 컷 촬영 부스입니다. 이 폴더 안에 필요한 것이 모두 있습니다.

**촬영 주소**: https://gtmc-history.github.io/history4cut/ (부스 번호는 `?booth=B1`, `?booth=B2`, `?booth=B3`)

```
history4cut/
├─ index.html   ← 기존 행사 운영본 (v2.0)
├─ chroma.html  ← 크로마키 행사판 (v2.4)
├─ share.html   ← 교사용 기기 저장 배포판 (v2.1)
├─ README.md
├─ server/      ← 관리자 화면 v2.6, Code.gs 수정 안내, 서버 연동 가이드 (Apps Script용, Pages와 무관)
└─ docs/        ← 운영 안내·검증 기록
```

- 실제 학생 사진을 찍기 전 초록천, 조명, 옷 경계를 확인하세요. 사진에 초록색 옷이 포함되면 일부가 지워질 수 있어 원본 선택이 필요합니다.

## 크로마키 시험판 (v2.1 · 2026-11-02)

- **원본 운영 주소**: https://gtmc-history.github.io/history4cut/ (`index.html`, 변경 없음)
- **초록천 합성 시험 주소**: https://gtmc-history.github.io/history4cut/chroma.html (`chroma.html`)
- 기본은 **아이보리 합성 / 제거 강도 보통**. 결과 화면에서 **강하게** 또는 **원본(초록천)**으로 전환할 수 있습니다.
- 원본 사진은 보존하고 합성 결과만 출력합니다. 스티커, 재촬영, 기기 임시 저장/복구, Google Drive 접수 형식은 기존과 동일합니다.
- **현장 확인 필수**: 실제 초록천·조명·초록색 옷·머리카락 경계 확인 → 파일 접수 → 인쇄 1장 테스트.
- 합성이 어색하거나 오류가 나면 **원본 운영 주소(index.html)**로 복귀합니다. 원본 파일을 교체하지 않았으므로 즉시 전환 가능합니다.
- GitHub Pages 반영까지 배포 지연이 있을 수 있습니다. 코드 파일이 존재하는 것과 웹페이지가 실제 서비스되는 것은 별도로 확인해야 합니다.

## 독서회 공간 선택 배경 (2026-11-02 추가)

- **행사용**: https://gtmc-history.github.io/history4cut/chroma.html
- **교사용 배포판**: https://gtmc-history.github.io/history4cut/share.html
- 촬영·결과 화면에서 **아이보리(기본) / 웜그레이 / 독서회 공간 / 원본**을 선택할 수 있습니다. `독서회 공간`은 GPT 이미지 생성으로 만든 **AI 상상 재구성**이며 실제 1929년 독서회 사진이나 검증된 장소 재현이 아닙니다.
- **실시간 합성 미리보기**와 최종 JPG에 동일한 배경이 적용됩니다. 배포판은 학생 정보를 전송하거나 서버에 사진을 저장하지 않으며, 사진 저장 버튼으로 JPG를 기기에 내려받습니다.
- 합성이 어색하거나 초록색 의상이 지워지면 원본 또는 단색으로 전환하세요. 학생 참여형 역사 미션·구호 스티커는 유지합니다.
- 기존 `index.html`은 변경하지 않았습니다. 실제 휴대폰 카메라, 조명, 초록천에서 한 번 촬영하고 접수·저장을 확인한 뒤 운영하세요.

## 크로마키 미리보기가 바뀌지 않을 때

- **초록천이 아닌 배경에서는** 원본 카메라 화면을 그대로 보여 주는 것이 정상입니다. 이 앱은 초록 픽셀을 선택 배경으로 교체하는 방식이며, 일반 배경에서 사람만 자동으로 분리하는 AI 기능은 사용하지 않습니다.
- 촬영 화면 **왼쪽 아래 ‘선택 배경’**에서 실제 선택한 이미지나 색상을 확인할 수 있습니다. 초록천이 잡히면 인물 뒤쪽이 실시간으로 합성됩니다.
- 오른쪽 아래 안내가 **‘초록천 미감지’**라면 초록천이 화면에 충분히 들어오는지 확인하고, 천을 팽팽하게 펴서 고르게 비춰 주세요. 합성이 약하면 **제거 강도 · 강하게**를 시험해 보세요.
- 머리카락·초록색 옷이 지워지면 제거 강도를 보통으로 되돌리거나 원본 모드로 전환하세요.
- 모바일 브라우저에 이전 화면이 남아 있으면 페이지를 새로고침해 주세요. 실사풍 독서회 공간은 실제 사료 사진이 아닌 **AI 상상 재구성**입니다.

## 배포

1. 이 저장소의 `index.html`이 GitHub Pages로 바로 배포됩니다. 수정은 이 파일만 고치면 됩니다.
2. **서버**: '받을 학생' 학번·이름을 저장하려면 `server/Code-gs-수정-v2.4.md`대로 Code.gs 다섯 곳을 바꾸고, `server/Admin.html` v2.6을 붙여 넣은 뒤 새 버전으로 배포합니다. 고치기 전에도 접수는 되고, 학번·이름만 저장되지 않습니다. (`server/서버-연동-가이드.md`) 접수 데이터는 기존과 같은 `characterId:'none'`으로 보냅니다.
3. 크롬북에서 한 장 찍어 스티커를 붙이고 접수한 뒤, 관리자 화면에서 인쇄용 사진에 스티커가 들어갔는지 봅니다.

## 사용할 수 있는 기기

- **크롬북(부스 권장)**: 최신 Chrome. 화면과 터치 모두 점검했습니다.
- **안드로이드 휴대폰**: 최신 Chrome. 세로·가로 모두 동작합니다. 사진이 가로 칸이라 **휴대폰은 가로로 들고 찍는 것**을 권합니다.
- **아이폰**: iOS 15.4 이상 Safari. 실기기 확인은 아직 하지 못했습니다.
- **내려받은 파일을 휴대폰·크롬북에서 바로 열면 카메라가 켜지지 않습니다.** (주소가 `content://`나 `file://`로 시작) 기기에서 카메라 권한을 허용해도 브라우저가 막습니다. 반드시 `https://` 촬영 사이트 주소로 여세요. 이 경우 첫 화면에 빨간 안내가 뜹니다.
- 카카오톡·인스타그램 등 앱 안 브라우저에서는 카메라가 막힐 수 있습니다. 주소를 Chrome이나 Safari에서 열어 주세요.
- 접수번호와 보관 사진은 기기마다 따로 저장됩니다. 한 팀은 한 기기에서 끝까지 진행해 주세요.

## 한 팀의 진행 흐름 (약 2~3분)

1. **시작**: '네 컷 촬영하기'
2. **촬영 + 역사 미션**: 컷마다 🎲 미션이 굴러가다 정해집니다. 화면 위에 미션이, 아래에 짧은 역사 설명이 나옵니다. 1~3컷은 무작위, 4컷은 늘 '오늘의 우리답게! 자유 포즈'입니다.
3. **디자인·꾸미기**: 세 가지 디자인 중 하나를 고르고, 역사 스티커를 눌러 붙인 뒤 손가락으로 끌어 옮깁니다. 크게·작게·지우기가 됩니다. 스티커를 누르면 그 소품이나 구호의 설명이 나옵니다.
   - **휴대폰 세로 화면**에서는 한 컷씩 크게 보여 줍니다. ◀ ▶로 컷을 넘기고, 사진이 화면 위에 고정되어 아래 스티커를 눌러도 계속 보입니다. 스티커는 보고 있는 컷에 붙습니다. '전체 보기'를 누르면 띠 전체가 보입니다.
4. **접수**: '사진 받을 학생'에 대표 1명의 학번·이름을 적고 접수하면 접수번호를 받습니다. 비워 두면 한 번 더 물어봅니다. 스티커는 인쇄되는 사진에 함께 들어갑니다.

## 역사 스티커

이모지 대신 1929년의 소품과 자료로 확인한 구호로 만들었습니다. 모두 페이지 안에 그려져 있어 파일을 따로 올리지 않아도 됩니다.

- **그날의 학생들 사진 카드**: 상단 AI 상상 삽화에서 남학생 둘, 여학생 둘을 잘라 낡은 사진처럼 만든 카드. '상상 삽화' 표시가 붙고, 특정 인물이 아니라고 설명합니다.
- **구호 말풍선**: 독립 만세 / 식민지 노예교육 철폐 / 조선인 본위 교육 실시
- **소품**: 통학 승차권(광주 ⇄ 나주), 1929·11·3 도장, 책 꾸러미

실존 인물(박준채·박기옥·이광춘 등)의 얼굴 그림은 넣지 않았습니다. AI가 지어낸 얼굴이 실제 모습으로 오해될 수 있기 때문입니다. 인물 이야기는 역사 미션 설명과 아래 배경 정보로 전합니다.
