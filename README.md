# 역사네컷 · 나주역 1929 (v1.9)

학생독립운동기념일(학생의 날) 행사용 네 컷 촬영 부스입니다. 이 폴더 안에 필요한 것이 모두 있습니다.

**촬영 주소**: https://gtmc-history.github.io/history4cut/ (부스 번호는 `?booth=B1`, `?booth=B2`, `?booth=B3`)

```
history4cut/
├─ index.html   ← 촬영 페이지 (이 파일 하나로 작동)
├─ README.md
└─ docs/        ← 운영 안내·검증 기록
```

## 배포

1. 이 저장소의 `index.html`이 GitHub Pages로 바로 배포됩니다. 수정은 이 파일만 고치면 됩니다.
2. **서버(Code.gs)는 고치지 않아도 됩니다.** 접수 데이터는 기존과 같은 `characterId:'none'`으로 보냅니다.
3. 크롬북에서 한 장 찍어 스티커를 붙이고 접수한 뒤, 관리자 화면에서 인쇄용 사진에 스티커가 들어갔는지 봅니다.

## 사용할 수 있는 기기

- **크롬북(부스 권장)**: 최신 Chrome. 화면과 터치 모두 점검했습니다.
- **안드로이드 휴대폰**: 최신 Chrome. 세로·가로 모두 동작합니다. 사진이 가로 칸이라 **휴대폰은 가로로 들고 찍는 것**을 권합니다.
- **아이폰**: iOS 15.4 이상 Safari. 실기기 확인은 아직 하지 못했습니다.
- **내려받은 파일을 휴대폰·크롬북에서 바로 열면 카메라가 켜지지 않습니다.** (주소가 `content://`나 `file://`로 시작) 기기에서 카메라 권한을 허용해도 브라우저가 막습니다. 반드시 `https://` 촬영 사이트 주소로 여세요. 이 경우 첫 화면에 빨간 안내가 뜹니다.
- 카카오톡·인스타그램 등 앱 안 브라우저에서는 카메라가 막힐 수 있습니다. 주소를 Chrome이나 Safari에서 열어 주세요.
- 접수번호와 보관 사진은 기기마다 따로 저장됩니다. 한 팀은 한 기기에서 끝까지 진행해 주세요.

## 한 팀의 진행 흐름 (약 2~3분)

1. **시작**: '네 컷 촬영하기'
2. **촬영 + 역사 미션**: 컷마다 🎲 미션이 굴러가다 정해집니다. 화면 위에 미션이, 아래에 짧은 역사 설명이 나옵니다. 1~3컷은 무작위, 4컷은 늘 '오늘의 우리답게! 자유 포즈'입니다.
3. **디자인·꾸미기**: 세 가지 디자인 중 하나를 고르고, 역사 스티커를 눌러 붙인 뒤 손가락으로 끌어 옮깁니다. 크게·작게·지우기가 됩니다. 스티커를 누르면 그 소품이나 구호의 설명이 나옵니다.
   - **휴대폰 세로 화면**에서는 한 컷씩 크게 보여 줍니다. ◀ ▶로 컷을 넘기고, 사진이 화면 위에 고정되어 아래 스티커를 눌러도 계속 보입니다. 스티커는 보고 있는 컷에 붙습니다. '전체 보기'를 누르면 띠 전체가 보입니다.
4. **접수**: 접수번호를 받습니다. 스티커는 인쇄되는 사진에 함께 들어갑니다.

## 역사 미션

| 미션 | 화면 설명 |
|---|---|
| 나주역 그날처럼, 부당함에 맞서는 눈빛 | 1929년 10월 30일 나주역, 박준채는 일본인 학생의 희롱에 맞섰어요. |
| 책을 펼쳐 든 독서회 학생처럼 | 독서회는 책을 함께 읽으며 민족 의식을 키운 학생 비밀 모임이에요. |
| 두 팔 번쩍, 만세를 외치듯 | 11월 3일과 12일, 광주의 학생들은 거리에서 함께 외쳤어요. |
| 어깨를 나란히, 같은 곳을 바라보며 | 광주에서 시작된 시위는 이듬해까지 전국 학생들에게 번졌어요. |
| 통학 기차를 기다리던 그날의 학생들처럼 | 광주와 나주를 오가던 통학 열차에서 사건이 시작되었어요. |
| 서로를 지켜 주듯 든든하게 | 한 사람의 항의에 많은 학생이 함께하며 운동이 커졌어요. |

문구는 `site/index.html`의 `MISSIONS` 목록에서 고칩니다.

## 역사 스티커

이모지 대신 1929년의 소품과 자료로 확인한 구호로 만들었습니다. 모두 페이지 안에 그려져 있어 파일을 따로 올리지 않아도 됩니다.

- **그날의 학생들 사진 카드**: 상단 AI 상상 삽화에서 남학생 둘, 여학생 둘을 잘라 낡은 사진처럼 만든 카드. '상상 삽화' 표시가 붙고, 특정 인물이 아니라고 설명합니다.
- **구호 말풍선**: 독립 만세 / 식민지 노예교육 철폐 / 조선인 본위 교육 실시
- **소품**: 통학 승차권(광주 ⇄ 나주), 1929·11·3 도장, 댕기, 책 꾸러미, 학생모

실존 인물(박준채·박기옥·이광춘 등)의 얼굴 그림은 넣지 않았습니다. AI가 지어낸 얼굴이 실제 모습으로 오해될 수 있기 때문입니다. 인물 이야기는 역사 미션 설명과 아래 배경 정보로 전합니다.

## 부스 진행자를 위한 배경 정보

| 인물 | 내용 |
|---|---|
| 박준채 | 1914~2001. 광주고보 2학년. 1929년 10월 30일 나주역에서 사촌 박기옥 등을 희롱한 일본인 학생에게 항의 |
| 박기옥 | 광주여고보 학생. 나주역에서 희롱당한 여학생 중 한 명 (박준채의 사촌. 누나·동생 여부는 자료마다 다름) |
| 이광춘 | 1914~2010. 광주여고보 학생. 나주역에서 함께 희롱당했고, 이후 백지동맹 주도. 1996년 건국포장 |

**자료 대조 결과 (2026-10 웹 검색)**
- 확인됨: 박준채 광주고보 2학년, 나주역에서 희롱당한 여학생 박기옥·이광춘·이금자, 11월 12일 격문의 '식민지 노예교육 철폐', 구호 '조선인 본위교육 실시'·'독립만세', 194개교 5만 4천여 명 참가
- 고친 것: 자료에서 확인하지 못한 '피압박 민족 해방 만세'는 '조선인 본위 교육 실시'로 바꿈. '조선 독립 만세'는 자료 표현대로 '독립 만세'로 바꿈.

## v1.7에서 바뀐 점

우리반네컷 코드에서 부스에 필요한 부분만 가져왔습니다.
- **미션 뽑기**를 '역사 미션'으로 바꿔 촬영 순서에 넣었습니다.
- **스티커 꾸미기**를 역사 소품·구호 스티커로 바꿔 넣었습니다. 끌어서 옮기기, 크게·작게, 지우기가 됩니다.
- 기기 보관 사진에도 스티커 위치가 저장되어, 새로고침 후 복구해도 그대로입니다.

가져오지 않은 것: 6장 중 4장 고르기, 프레임 색상표, 이모지 스티커, 휴대폰 카메라 앱 연동. 부스 진행 속도를 늦추거나, 시대에 맞지 않거나, 크롬북 부스에는 필요 없기 때문입니다.
