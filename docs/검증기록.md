- 고친 것: 다시 찍기·보관 목록 버튼을 44px 이상으로 키움 / 높이가 낮은 화면에서는 촬영 영역으로 자동 스크롤 / 휴대폰에서 스티커를 붙이면 그 스티커가 보이게 스크롤 / roundRect가 없는 구형 Safari(iOS 15)용 대체 코드
- 확인하지 못한 것: 아이폰 Safari 실기기(이 환경에 Safari 엔진 없음), 실제 크롬북 카메라, 학교 관리 정책
