# v1.4 검증 결과

Chrome 브라우저 자동화와 모의 카메라·서버로 검증했습니다. 실제 크롬북 검증과 서버 재배포는 수행하지 않았습니다.

- 통과: 실제 촬영 경로의 모의 영상 네 컷을 JPG·원본·번호와 함께 저장
- 통과: 초기화 확인 취소·다음 팀 보관·새로고침 후 원본/최종 JPG/접수번호 정확히 복구
- 통과: 디자인 변경·한 컷 재촬영 후 저장본 갱신, 다른 세 장 보존
- 통과: 3회 전송 실패 후 다음 팀 가능·새로고침 후 동일 payload 복구·실패 사진 편집 차단
- 통과: 전송 중 다음 팀 촬영·이전 팀 응답이 새 팀 화면에 간섭하지 않음·성공 후 사진 데이터 삭제
- 통과: 초기화 확인 승인 시 해당 팀의 기기 사진만 삭제
- 통과: 카메라 권한 대기 취소·취소 후 뒤늦게 허용된 스트림 즉시 종료
- 통과: 저장 용량 실패 시 다음 팀 차단·사진 다운로드 유지·미보관 상태 네트워크 전송 금지
- 통과: 미접수 사진은 24시간 경과에도 보존·정리 안내, 사진 없는 완료 기록만 자동 정리
- 통과: 동일 브라우저 두 탭에서 같은 접수 재전송 시 Web Locks로 중복 작업 차단
- 통과: 전송 도중 새로고침 후 동일 요청 재전송·중복 성공 응답 처리
- 통과: 모바일 가로 넘침·JavaScript 오류 없음

브라우저 JavaScript 오류: 0건.
v1.3에서 확인한 실제 서버 연결 방식은 유지했습니다. 이번 검증에서는 실제 드라이브에 테스트 사진을 추가하지 않았습니다.
